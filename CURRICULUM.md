# OSINT Training Curriculum

8-week structured learning path covering all 8 modules. Total estimated time: 22 hours.

---

## Phase 1: Foundation (Weeks 1-2)

**Modules:** 01 OSINT Fundamentals, 02 Domain & Infrastructure Recon
**Hours:** ~5

| Week | Module | Activities | Deliverable |
|------|--------|------------|-------------|
| 1 | 01 - OSINT Fundamentals | Intelligence cycle theory, legal frameworks, OPSEC review | Collection plan for a fictional target organization |
| 2 | 02 - Domain & Infrastructure Recon | DNS enumeration, WHOIS, certificate transparency labs | Domain reconnaissance report (JSON + analysis) |

**Milestone:** Ability to plan and execute structured domain-level OSINT collection with proper documentation.

---

## Phase 2: Core Skills (Weeks 3-5)

**Modules:** 03 Network Intelligence, 04 Web OSINT, 05 Social Media OSINT, 06 Threat Intelligence
**Hours:** ~12

| Week | Module | Activities | Deliverable |
|------|--------|------------|-------------|
| 3 | 03 - Network Intelligence | IP/ASN analysis, Shodan queries, CIDR enumeration | Network intelligence report on a target IP range |
| 4 | 04 - Web OSINT | Technology fingerprinting, Wayback Machine, resource extraction | Web application OSINT report with tech stack analysis |
| 4 | 05 - Social Media OSINT | Username enumeration, platform checks, profile correlation | Username investigation profile card |
| 5 | 06 - Threat Intelligence | IOC analysis, VirusTotal/AbuseIPDB queries, ATT&CK mapping | Threat intelligence brief for a set of IOCs |

**Milestone:** Full-spectrum OSINT collection capability across network, web, social, and threat intelligence domains.

---

## Phase 3: Advanced and Automation (Weeks 6-8)

**Modules:** 07 Geospatial Intelligence, 08 OSINT Automation
**Hours:** ~5

| Week | Module | Activities | Deliverable |
|------|--------|------------|-------------|
| 6 | 07 - Geospatial Intelligence | EXIF extraction, geolocation, map generation | GEOINT analysis report with interactive map |
| 7-8 | 08 - OSINT Automation | Framework integration, workflow orchestration, HTML reporting | Automated OSINT framework producing unified dashboard reports |

**Milestone:** End-to-end automated OSINT pipeline that combines all prior module techniques into a single workflow.

---

## Recommended Weekly Schedule

- **Theory and tool review:** 1 hour
- **Hands-on lab work:** 1.5-2 hours
- **Documentation and report writing:** 30 minutes

---

## Completion Criteria

- All 8 lab exercises completed with output artifacts
- At least one full automated recon run (Module 08) against an authorized target
- Portfolio of OSINT reports demonstrating each collection discipline
